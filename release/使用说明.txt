广轻活动汇总（Windows 64 位）

新版请双击“广轻活动汇总-Excel提醒版.exe”，不需要安装 Python、Node.js 或浏览器扩展。
更新时请先关闭旧版窗口；原活动结果与登录状态仍使用同一用户数据目录。

课表功能
1. 点击顶栏“使用说明”右侧新增的“课表”按钮。
2. 点击“教务登录”，在程序内登录 https://jw.gdipu.edu.cn/jsxsd/framework/xsMain.jsp 。
3. 返回“我的课表”，点击“一键导入课表”。程序尝试打开个人课表并读取当前查询结果。
4. 如果系统菜单没有自动定位，请在“教务系统登录”页手动打开“学生个人课表”，选择学期并查询，再点击“一键导入课表”。
5. 可选择第几周查看；已识别的单双周会自动筛选。课表存到用户数据目录 timetable.json，重启后可离线查看。
6. 网格为星期一至星期日、六个时段，与你提供的时间一致：
   第1、2节 08:30–09:55；第3、4节 10:15–11:40；
   第5、6节 14:00–15:25；第7、8节 15:45–17:10；
   第9、10节 18:30–19:55；第11、12节 20:00–21:25。
7. 登录失效、课表为空或无法识别时，不覆盖已导入课表。

课表日期与手动课程
1. 点击“设置日期”，选择任意周次、星期和这一天的实际日期。程序会自动推算第1周周一，并在切换具体周次时显示星期一至星期日的日期。
2. 日期设置会保存在本机；重新启动或重新导入教务课表不会丢失。
3. 点击“新增课程”，填写课程名称、教师、地点、星期、节次和上课周次。周次支持“2”“2-6”“1-8单周”等格式。
4. 手动课程会显示“手动添加”标记；点击课程卡片右上角“×”可以删除。
5. 重新一键导入只更新教务课程，会保留手动课程，适合记录尚未同步到教务系统的临时调课。

活动过滤与报名提醒
1. 活动名称中包含“团日”或“班会”，以及活动类型为“班级活动”的项目会自动排除，不进入活动汇总、统计、Excel 导出和课表提醒。
2. 其他活动会生成两种独立提醒；必须先在课表中设置日期，并切换到具体周次。
3. 报名开始时间生成橙色“活动报名提醒”卡片，活动开始时间生成蓝色“活动开始提醒”卡片。即使同一时段已有课程，也会作为单独卡片显示。
4. 提醒卡只显示对应时间、活动名称和地点，不显示报名截止时间。
5. 时间段按课表起始时间划分：10:15、14:00、15:45、18:30、20:00 分别进入后一个时段；例如 10:00 属于第1、2节时段，10:30 属于第3、4节时段。

操作步骤
1. 点击“学校登录”，在程序窗口内完成学校统一认证。
2. 登录成功后点击“开始采集”。程序自动翻页读取“未开始”活动，并进入详情提取报名时间和名额。
3. 在“活动汇总”页查看结果，默认按报名开始时间升序排列。
4. 可按关键词、活动类型、报名状态筛选，再点击“导出 Excel”选择保存位置。导出的 .xlsx 使用当前筛选结果，并按报名开始时间升序排列，可直接用 Excel / WPS 打开。
5. “保存网页”可保存当前全部结果的离线网页快照；“停止采集”保留已经读取的结果。

登录和数据
- 第一次需要在这个程序内登录。它不共享 Chrome、Edge 或 Codex 内置浏览器的登录。
- 后续会复用自身登录状态，会话过期时重新登录。程序不采集密码，也不自动报名。
- 上次采集结果和浏览器登录状态保存在：%LOCALAPPDATA%\GdipuActivityHelper
- 程序关闭后，已导出的 Excel 文件仍然可用。

数据口径
- “未开始”表示活动尚未举办，不一定是报名尚未开始。
- 报名开始/截止时间、总名额、剩余名额从详情读取。列表“已参加人数”不作为活动总名额。
- 报名状态按北京时间计算；是否符合报名资格以学校详情页为准。
- 同名不同活动分别保留。部分详情读取失败会标出原因；列表中途变化时会停止并提示重试。

运行环境
- Windows 10/11 64 位，.NET Framework 4.6.2 或更新版本，以及 Microsoft Edge WebView2 Runtime。
- 当前电脑已检测到 WebView2；移动到其他缺少该组件的电脑时，可从微软官方网站安装：
  https://developer.microsoft.com/microsoft-edge/webview2/
